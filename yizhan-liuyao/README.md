# Yizhan Liuyao — local Skill / 易占本地六爻

Offline chart calculation + guidance for your own AI. No account, API key or Yizhan subscription required. This is a local prototype, not a guarantee of predictive accuracy.

## Install / 安装

Python 3.10+:

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/cast.py --lines 7 8 7 8 6 8 --timestamp 2026-10-04T06:00:00+08:00
```

Copy this entire directory into your AI tool's supported skills directory, retaining the name `yizhan-liuyao`. Activate the skill using your tool's normal mechanism. Tools that cannot execute Python cannot calculate a chart with this package. In that case, run the CLI yourself and provide its JSON plus the reading guidance to your AI.

中文：把整个目录安装到支持 Skill 的工具中。不能只复制 SKILL.md；脚本和 vendor 数据缺一不可。先运行上面的固定案例确认安装成功，再输入自己的问题和真实摇卦结果。六爻值从初爻到上爻，时间必须带时区偏移。

For a requested simulated cast: replace `--lines ...` with `--random`. No outbound requests occur during chart calculation. Dependency installation requires access to your package repository. Interpretations are generated by your host AI, whose own data handling and charges apply.

## Scope / 边界

- Structural chart data included; scanned books, OCR texts and user records excluded.
- Fixed UTC+08 calendar convention, late Zi retains civil day; not true solar time.
- Basic interpretation uses model knowledge unless users connect their own sources.
- Paid cloud retrieval, accounts, billing and affiliate tracking are **not implemented**.
- Windows tested locally; macOS/Linux not yet tested. See VALIDATION.md for exact evidence.
